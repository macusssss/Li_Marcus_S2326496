# Icon credits

The situation-type icons in `app/src/main/res/drawable-nodpi/` are 250px PNG renderings
of road-sign SVGs from Wikimedia Commons. Every file below is marked **Public domain** on its
Commons page (checked 22 November 2026).

| App icon | Used for | Commons file | Licence |
|---|---|---|---|
| `ic_type_roadworks.png` | Roadworks (MaintenanceWorks) | [Zeichen 123 - Arbeitsstelle, StVO 2013.svg](https://commons.wikimedia.org/wiki/File:Zeichen_123_-_Arbeitsstelle,_StVO_2013.svg) | Public domain |
| `ic_type_queue.png` | Queuing / abnormal traffic | [Zeichen 124 - Stau, StVO 1992.svg](https://commons.wikimedia.org/wiki/File:Zeichen_124_-_Stau,_StVO_1992.svg) | Public domain |
| `ic_type_closed.png` | Road closed / no lanes open | [Zeichen 250 - Verbot für Fahrzeuge aller Art, StVO 1970.svg](https://commons.wikimedia.org/wiki/File:Zeichen_250_-_Verbot_f%C3%BCr_Fahrzeuge_aller_Art,_StVO_1970.svg) | Public domain |
| `ic_type_lanes.png` | Lane restrictions | [UK traffic sign 516.svg](https://commons.wikimedia.org/wiki/File:UK_traffic_sign_516.svg) | Public domain |
| `ic_type_other.png` | Any other incident | [Zeichen 101 - Gefahrstelle, StVO 1970.svg](https://commons.wikimedia.org/wiki/File:Zeichen_101_-_Gefahrstelle,_StVO_1970.svg) | Public domain |

The launcher icon (`res/drawable/ic_launcher.xml`) is an original vector drawn for this app.
